# Disseny Studio

Quiero crear el sitio web de "Disseny", una empresa de Córdoba, Argentina, que fabrica bases de sommier de ecocuero y hace trabajos de metalúrgica a medida y en cantidad (sillas, mesas, estanterías, licitaciones) para mueblerías y compradores mayoristas. Tono de marca: corporativo y serio.

Armá el proyecto en React + Tailwind con estas páginas/secciones: Inicio, Portafolio, Servicios, Sobre nosotros, Cotizador, Contacto.

Concepto visual: todo el sitio simula una mesa de trabajo de diseño industrial. Fondo tipo plano técnico azul (cianotipo/blueprint) con textura de papel real, líneas de grilla finas y anotaciones sutiles de medidas. Paleta de colores: azul como base dominante, rojo y amarillo como acentos (pensalos como colores de señalización industrial: cinta de precaución, sellos de aprobado), nunca colores infantiles. Tipografía: fuente técnica/tipo stencil para títulos, sans-serif limpia para el cuerpo de texto.

Dirección de arte: buscá que todo se vea fotorrealista y de producción alta — texturas de materiales reales (papel, metal, madera), iluminación de estudio con sombras suaves — nada de flat design ni ilustración plana tipo clipart.

Todavía no tengo logo definitivo: dejá un placeholder circular simple con la letra "D".

Por ahora armá solo la estructura general y el estilo base (fondo, tipografía, paleta, layout de las secciones con contenido de placeholder). Los componentes interactivos específicos (sidebar, botones, formulario, etc.) te los voy a ir pasando en mensajes siguientes con su código.
